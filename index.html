Stage 1 - Single tool use. The agent picks one tool, calls it once, observes the result, and answers. The loop always runs exactly twice.
Stage 2 - ReAct loop. The agent reasons and acts in multiple rounds, chaining tools in sequence until the goal is fully complete.
Stage 3 - Memory. The agent remembers facts across sessions. Tell it your name and city — it saves them and uses them next time.
Stage 4 - Multi-agent. One orchestrator delegates to 3 specialist agents running in parallel. Results are synthesised into a final briefing.
